## Known defects of this run

- **AMOTR** is a typo of AMTOR in the scanner's table - UNSUPPORTED is the right answer to a wrong name,
  not a missing command.
- **TRANS** was probed by this version. It leaves the command mode, so **TRFLOW** and **XFLOW** answered
  ERROR afterwards. The operator then confirmed both in the terminal as present and EXPERT-locked
  (`XFLOW ON`, `TRFLOW OFF` after `EXPERT ON`, 28.07.2026).
- **CALIBRATE** was not probed (keys the transmitter tones) - correct.
- The `mnem` column is the scanner's HYPOTHESIS (`gen_hyp`, `conf`), not a measured Host Mode mnemonic.
- `SUPPORTED` does not say whether EXPERT had to be ON for the command.
