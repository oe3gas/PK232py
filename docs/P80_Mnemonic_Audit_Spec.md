## Teil A — Register: `comm/mnemonic_registry.py`

Qt-frei, **eine** Stelle:

```python
@dataclass(frozen=True)
class MnemonicEntry:
    mnemonic: bytes
    meaning: str            # e.g. "PACKET mode switch", "XMIT (key TX)"
    kind: str               # "mode" | "param" | "query" | "action" | "channel"
    evidence: dict[str, str]  # release -> "T151 log 20261001_205535" / "TRM 4.3.3"
    transmits: bool = False   # keys the transmitter (XM, CQ, ...)
```

- Je Kürzel aus B.2 ein Eintrag. `evidence` aus vorhandenen Belegen:
  `host_params.verified_releases` (automatisch übernehmen, nicht
  abschreiben), Testplan-Einträge mit Log, TRM-Abschnitt nur als
  `"TRM <Abschnitt>, unmeasured"`.
- Kein Beleg → `evidence = {}` und `meaning` mit Quelle (Matrix-Zeile,
  STABO-Seite).

**Commit:** `comm: mnemonic registry with evidence per release`

## Teil B — Prüftest (statisch, CI)

`tests/test_mnemonic_registry.py`:
1. Scannt `src/pk232py` (ohne `tests`) nach jedem Literal-Kürzel in

   `tools/gen_mnemonic_audit.py`).

## Teil D — Messpaket `hw_check.py mnemonic_probe` (nach Teil C)

Nur für Kürzel **ohne Beleg**, nur die Arten `mode`, `param`, `query`.
**Keine** `action`- und **keine** `transmits`-Kürzel (die bekommen bei
Bedarf ein eigenes Paket mit `confirm_tx`).

- `mode`: Host-Frame senden, Antwort roh loggen, dann `OP`-Abfrage →
  erwarteter Wert aus dem TRM 4.3.2 (z. B. `OPBA`); danach zurück auf
  `PA` und `OP` prüfen. Kein Senden auf der Luft (Moduswechsel tasten
  nicht).
- `param`: wie `host_params_probe` Teil A (Abfrage, Testwert, Rücklesen,
  verbose Gegenprüfung, Rückstellung im Host Mode) — Neue Parameter als
  Zeilen in `host_params.py` aufnehmen statt eine zweite Probe zu bauen,
  wo das passt; nur Kürzel ohne verbose Namen hier separat.
- `query`: Abfrage, Antwort roh.
- Mit `operator_step()`, nur PC 1, `--exclude`, Ergebnis je Kürzel, das
  Register wird aus dem Log per `--reevaluate` ergänzt (kein Abschreiben).

Läufe: T166 Gerät B, T167 Gerät A (je Gerät vorher aus-/einschalten).

**Commits:**
```
hw_check: mnemonic_probe for unproven mode, param and query mnemonics
Testplan: T166 T167 mnemonic probe
```
